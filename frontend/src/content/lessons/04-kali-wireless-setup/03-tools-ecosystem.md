# Tools Ecosystem — Kismet, Airodump, Wireshark, Scapy, WiFiForge

## Learning Objectives
- Understand wireless tool ecosystem: recon, capture, analysis, audit, lab, reporting
- Learn Kismet, airodump-ng, Wireshark, tshark, Scapy, hcxdumptool, wash, hostapd, FreeRADIUS
- Understand WiFiForge built-in tools: PcapInspector, ConfigViewer, AttackDefenseRetest, ReportEditor
- Learn tool selection based on phase: Recon → Enum → Vuln → Exploit → Report
- Understand zero-cost vs hardware tools

## Theory

### Tool Categories

**Recon & Capture (Passive, 0 RF tx, undetectable, or active with probe):**
- **Kismet:** Wireless IDS, detector, sniffer, WIDS — passive, no tx, detects APs, clients, hidden SSIDs, WPS, BT, Zigbee, etc., logs to pcap, kismetdb, web UI, great for recon, WIDS authorized list, rogue detection
  - Install: `apt install kismet`
  - Use: `kismet -c wlan0`, web UI `http://localhost:2501`, logs to `~/.kismet/`
  - For PT: Recon, WIDS, rogue detection, hidden SSID, client enumeration, evidence

- **airodump-ng (Aircrack-ng):** 802.11 packet capture, shows BSSID, PWR, Beacons, #Data, CH, MB, ENC, CIPHER, AUTH, ESSID, STATION, etc., channel hopping, writes pcap, great for recon, handshake capture
  - Install: `apt install aircrack-ng`
  - Use: `airmon-ng check kill`, `airmon-ng start wlan0`, `airodump-ng wlan0mon`, `airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon`
  - For PT: Recon, handshake capture (lab only), client enumeration

- **hcxdumptool + hcxtools:** Capture EAPOL, PMKID, EAP, etc., converts to hashcat format, great for PMKID clientless, EAPOL, etc.
  - Install: `apt install hcxtools` or build from GitHub
  - Use: `hcxdumptool -i wlan0 -o capture.pcapng --enable_status=1`, `hcxpcapngtool -o capture.hc22000 capture.pcapng`, `hashcat -m 22000 capture.hc22000 wordlist`
  - For PT: PMKID, handshake, EAP, hashcat conversion

- **Scapy (Python):** Packet manipulation, generation, parsing — this academy uses Scapy to generate 16 real PCAPs — beacon, probe, auth, assoc, EAPOL, deauth, WPS, WPA3, rogue, captive, enterprise, EAP, RADIUS, corporate, methodology — zero-cost, local-first, reproducible, no hardware
  - Install: `pip install scapy`
  - Use: `python3 scripts/generate_pcap.py --type beacon --ssid LAB-WIFI --bssid AA:BB:CC:DD:EE:FF --channel 6 -o beacon-only.pcapng`, `scapy` interactive, `rdpcap`, `wrpcap`, `Dot11`, `Dot11Beacon`, `Dot11ProbeReq`, `Dot11Auth`, `Dot11AssoReq`, `EAPOL`, etc.
  - For PT: PCAP generation, parsing, analysis, simulated labs, this academy

**Analysis (PCAP, config, logs):**
- **Wireshark:** GUI packet analyzer, display filters, 802.11, EAPOL, EAP, RADIUS, WPS, RSN, HT/VHT/HE, etc., great for analysis, evidence collection, reporting
  - Install: `apt install wireshark`
  - Use: `wireshark capture.pcapng`, filters `wlan.fc.type_subtype==8`, `eapol`, `wps`, `wlan_mgt.ssid==LAB-WIFI`, `wlan.bssid==AA:BB:CC:DD:EE:FF`, etc.
  - For PT: Analysis, evidence, reporting, frame numbers, IE decoding

- **tshark (Wireshark CLI):** CLI version of Wireshark, for scripting, automation, parsing, great for evidence collection, this academy backend uses tshark if available, fallback to Scapy
  - Install: `apt install tshark`
  - Use: `tshark -r capture.pcapng -Y "wlan.fc.type_subtype==8" -T fields -e wlan.bssid -e wlan_mgt.ssid -e wlan_mgt.ds.current_channel`, `tshark -r capture.pcapng -Y eapol -T json`
  - For PT: Analysis, scripting, evidence, backend PCAP parser

- **PcapInspector (WiFiForge):** Built-in PCAP analyzer — this platform — uses backend FastAPI `/api/pcaps/{id}/analyze` with tshark → Scapy → mock fallback, shows summary (SSIDs, BSSIDs, clients, channels, beacons, probes, EAPOL, deauth, WPS), filter presets (beacon, probe req/resp, EAPOL, EAP, RADIUS, auth, deauth, WPS), frames table with type badges, frame detail, evidence collection, zero-cost, local-first
  - Use: In ModuleDetail Lab tab, select PCAP, apply filter, click frame for detail, collect evidence
  - For PT: Analysis, evidence, reporting, simulated labs

- **ConfigViewer (WiFiForge):** Built-in config auditor — this platform — shows hostapd.conf, wpa_supplicant.conf, FreeRADIUS clients.conf, users, with issues (critical/high/medium/low) and recommendations, fixed config toggle, evidence collection
  - Use: In ModuleDetail Lab tab, shows bad config vs good config, issues with line, severity, message, recommendation, fix
  - For PT: Config audit, evidence, remediation, retest

- **AttackDefenseRetest (WiFiForge):** Built-in VAPT loop — this platform — shows Attack (title, description, evidence, impact), Defense (title, description, config snippet), Retest (title, description, verification), methodology reinforcement
  - Use: In ModuleDetail Lab tab, after PcapInspector and ConfigViewer, shows VAPT loop for module
  - For PT: Methodology, impact, remediation, retest

**Audit (Authorized only, offline, wordlists, hashcat, etc.):**
- **aircrack-ng:** WEP and WPA/WPA2 crack (authorized only) — PTW for WEP, dictionary for WPA2
  - Install: `apt install aircrack-ng`
  - Use: `aircrack-ng -w wordlist.txt capture.cap` (WPA2), `aircrack-ng capture.cap` (WEP PTW)
  - For PT: WEP key recovery (lab only, Critical), WPA2 offline audit (authorized only, weak PSK)

- **hashcat:** Advanced password recovery — modes 22000 WPA2 EAPOL+PMKID, 16800 WPA2 PMKID, 5500 NetNTLMv1/MSCHAPv2, 2500/2501 WPA/WPA2, etc.
  - Install: `apt install hashcat`
  - Use: `hashcat -m 22000 capture.hc22000 wordlist.txt`, `hashcat -m 5500 mschapv2.txt wordlist.txt`, `hashcat -m 16800 pmkid.txt wordlist.txt`
  - For PT: WPA2 handshake, PMKID, EAP MSCHAPv2 (authorized only)

- **hcxpcapngtool (hcxtools):** Converts pcapng to hashcat format — 22000, 16800, 5500, etc.
  - Install: `apt install hcxtools`
  - Use: `hcxpcapngtool -o capture.hc22000 capture.pcapng`, `hcxpcapngtool -o mschapv2.txt -E eap.txt capture.pcapng`
  - For PT: Conversion for hashcat

- **wash (Reaver):** WPS enumeration — shows WPS APs, BSSID, channel, RSSI, WPS version, locked, etc.
  - Install: `apt install reaver`
  - Use: `wash -i wlan0`, `wash -i wlan0mon`
  - For PT: WPS enumeration, detect WPS IE, 11k flaw

- **reaver / bully (WPS PIN brute-force, lab only):** WPS PIN brute-force — 11k max, not 100M, halves flaw, rate limiting, lockout
  - Install: `apt install reaver bully`
  - Use: `reaver -i wlan0mon -b BSSID -vv`, `bully -b BSSID -c CH -e SSID wlan0mon` (lab only, WPS enabled AP, own lab, not prod)
  - For PT: WPS PIN brute-force (lab only, own AP, not prod, may be illegal without authorization, DoS)

**Lab (AP, client, RADIUS, Docker):**
- **hostapd:** AP daemon — creates AP with SSID, BSSID, channel, security, WPS, PMF, etc. — for rogue AP lab, Evil Twin lab, captive portal lab, Enterprise lab
  - Install: `apt install hostapd`
  - Use: `hostapd hostapd.conf`, `hostapd.conf` with `interface=wlan0`, `ssid=LAB-WIFI`, `hw_mode=g`, `channel=6`, `wpa=2`, `wpa_key_mgmt=WPA-PSK`, `rsn_pairwise=CCMP`, `wpa_passphrase=StrongPass123`, `wps_state=0`, `ieee80211w=2`, `ap_isolate=1`, etc.
  - For PT: Rogue AP, Evil Twin, captive portal, Enterprise, lab

- **wpa_supplicant:** Client supplicant — connects to AP with SSID, PSK, EAP, ca_cert, etc. — for Enterprise lab, EAP lab, client behavior
  - Install: `apt install wpasupplicant`
  - Use: `wpa_supplicant -i wlan0 -c wpa_supplicant.conf`, `wpa_supplicant.conf` with `network={ ssid=\"LAB-WIFI\" key_mgmt=WPA-PSK psk=\"StrongPass123\" }` or `network={ ssid=\"Corp-Enterprise\" key_mgmt=WPA-EAP eap=PEAP identity=\"user@corp.com\" password=\"...\" ca_cert=\"/etc/certs/ca.pem\" subject_match=\"CN=radius.corp.com\" phase2=\"auth=MSCHAPV2\" }`
  - For PT: Client, Enterprise, EAP, cert validation

- **FreeRADIUS:** RADIUS server — for Enterprise lab, EAP, RADIUS, users, clients.conf, eap.conf
  - Install: `apt install freeradius`
  - Use: `freeradius -X`, `clients.conf` with `client AP1 { ipaddr=192.168.1.1 secret=StrongRandomSecret123!@#With22+Chars }`, `users` with `user1 Cleartext-Password := \"StrongPass\" Tunnel-Type=VLAN, Tunnel-Medium-Type=IEEE-802, Tunnel-Private-Group-Id=100`, `eap.conf` with `ca_cert`, `server_cert`, `private_key`
  - For PT: Enterprise, EAP, RADIUS, weak secret, users, RadSec

- **Docker / Docker Compose:** Containerized labs — hostapd, FreeRADIUS, portal, etc. — reproducible, zero-cost, local-first
  - Install: `apt install docker.io docker-compose`
  - Use: `docker-compose up`, `docker-compose.yml` with services hostapd, radius, portal, etc.
  - For PT: Local labs, reproducible, this academy future

**Reporting:**
- **ReportEditor (WiFiForge):** Built-in finding editor — this platform — Title, Severity, Description, Technical Details, Affected Component, Evidence, Impact, Recommendation, References, Retest, markdown preview, export MD, save draft to localStorage
  - Use: In Reports page, edit finding, preview markdown, export MD, save draft
  - For PT: Reporting, evidence, impact, remediation, professional VAPT

- **Wireshark / tshark:** Screenshots, frame numbers, filters, IE decoding — evidence for report

### Zero-Cost vs Hardware

**Zero-cost (simulated, no hardware, PCAPs/configs/logs):**
- All recon, enum, vuln, exploit simulated via PCAPs/configs — 16 PCAPs real Scapy-generated, 5 configs, PcapInspector, ConfigViewer, AttackDefenseRetest, ReportEditor — this academy Phase A-C
- Tools: Scapy, Wireshark, tshark, PcapInspector, ConfigViewer, ReportEditor — free, open-source, local-first
- Cost: ₹0 / $0 — as per requirement.md

**Hardware (real RF, USB adapter with monitor+injection+AP mode, authorized lab only):**
- Real RF capture, injection, AP, client, RADIUS — ALFA AWUS036ACHM MT7612U dual band or AWUS036NHA AR9271 2.4 GHz only — ~$30-40
- Tools: Kismet, airodump-ng, aireplay-ng, hostapd, wpa_supplicant, FreeRADIUS, hcxdumptool, wash, reaver, bully, hashcat, Docker
- Cost: $30-40 for adapter, but simulated first, hardware later where genuinely required — as per requirement.md

**For PT:** Start zero-cost simulated, master methodology, evidence, reporting, then add hardware for RF validation where needed — don't buy hardware immediately.

## VAPT Relevance

- **Tool selection:** Based on phase — Recon (Kismet, airodump-ng, Scapy, PcapInspector), Enum (Wireshark, tshark, ConfigViewer), Vuln (ConfigViewer, PcapInspector), Exploit (Simulated PCAPs, hardware aircrack/hashcat/reaver/hostapd), Report (ReportEditor, Wireshark screenshots)
- **Evidence:** Each tool produces evidence — PCAP hash, frame numbers, filters, config hash, logs, screenshots, commands — chain of custody
- **Methodology:** Tools support methodology Learn→Report, not replace — understand protocol, then use tool

## Common Mistakes

- Using iwconfig deprecated, not iw
- Not checking rfkill, NetworkManager interfering with monitor mode
- Not setting regdom, missing channels
- Using built-in Intel without monitor/injection for hardware labs, injection test fails
- Running deauth in prod without ROE, DoS, illegal
- Testing public Wi-Fi without authorization, violate CFAA
- No evidence — just running command, no frame numbers, hashes, config snippets
- Tool without understanding — running aircrack-ng without understanding handshake, PMK, PTK, MIC

## Evidence Collection

- Tool, command, output, PCAP hash, frame numbers, filters, BSSID, SSID, channel, client MAC, config hash, logs, screenshots
- Example: `Tool airodump-ng, command airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon, output capture-01.cap, PCAP hash abc123, Frame 1 Beacon SSID LAB-WIFI BSSID AA:BB:CC:DD:EE:FF Ch6 WPA2-PSK CCMP, Frame 9-12 EAPOL M1-M4 ANonce SNonce MIC complete`

## Attack → Defense → Retest

- **Attack:** No tools, can't recon, can't capture, can't analyze, can't audit, can't report
- **Defense:** Use tools based on phase — Kismet/airodump for recon, Wireshark/tshark/PcapInspector for analysis, ConfigViewer for config audit, AttackDefenseRetest for VAPT loop, ReportEditor for reporting, Scapy for PCAP gen, hostapd/FreeRADIUS for lab, hashcat for audit (authorized only)
- **Retest:** Tools show fix — beacon no WPS IE, PMF required, handshake audit fails, rogue detection, VLAN ping fails, etc.
