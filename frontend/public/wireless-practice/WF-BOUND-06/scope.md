# WF-BOUND-06 — Post-association boundaries

Available: offline evidence review and a local, deterministic policy calculation. No router, VLAN, firewall, service, authenticated client or cloud lab is running. `review-policy.py` reads local JSON only; it sends no requests and changes no firewall, route or device configuration. Its result is a MODEL decision, never a measured network result. The browser command simulator cannot execute Python.

The fictional owner approves exactly F1–F7 in flows.json for a future isolated lab, with their listed client, service, direction, TCP port 443 and at most one application request per flow per approved window. F8 deliberately changes the protocol/port and is NOT IN SCOPE. This file authorizes only reasoning about supplied files, not actual contact with a real network. Service aliases are not resolvable targets. A future implementation needs separate written permission, synthetic identities, approved endpoints, maximum duration, impact stops and cleanup.

Two test clients are modeled: guest-A and corp-B. Their zones/VLANs are fictional owner assertions in topology.json, not deductions from IP addressing or captured frames. Management services are out of policy for both; management administrator access is outside this exercise. Return traffic/stateful behavior, NAT, IPv6, endpoint firewalls, proxies and vendor ACL syntax are not implemented by the small stateless teaching evaluator.

baseline-policy.json has an overbroad guest rule; hardened-policy.json is a separate proposed model revision. Their authored observation records include application/health/route and rule decisions, as well as a deliberately inconclusive flow. They are not collected logs and not a deployed baseline or performed retest. Both acceptance and denial can be correct under the intended policy; absence of a response alone is not proof of enforcement.

corporate-attacks.pcapng (19 frames) and its JSON are copied from the existing teaching catalogue. They are a separate synthetic scene, not the source of the policy-model records. In particular, its ICMP pair is not an application test, VLAN assignment, successful PEAP attack or proof of a segmentation bypass. Addresses in that file are data, not target permissions. Do not scan them or reuse any credential shown in the fixture.

Mark live association, route/VLAN placement, ACL enforcement, endpoint authorization, application access and remediation effectiveness NOT TESTED. Hosted execution remains unavailable. Browser-only learners may review reference-results.json and record “supplied-result review, not independently calculated”. Download/cache files before working offline; verify SHA256SUMS for byte consistency, not proof of genuine collection or custody. Complete the worksheet before the public rubric. No trusted grading or certification is supplied.
