# Audit & Roadmap — superseded

This file previously carried self-scores and a platform-feature roadmap (leaderboards, XP shop, mentor
matching, plugin marketplace, GraphQL, mobile apps). That direction conflicted with the project's purpose —
a technically accurate, realistic, hands-on wireless VAPT academy — and with the review instruction to
prioritise learning value over platform features.

The current audit, the disposition of every suggestion, the verification commands and the learning-first
roadmap now live in:

* **[`docs/REVIEW_AND_DECISIONS.md`](REVIEW_AND_DECISIONS.md)** — findings F1–F8, the 22-item disposition
  table (implemented / modified / merged / deferred / rejected), improvements beyond the list, and the roadmap.
* [`docs/SIMULATION_VS_HARDWARE.md`](SIMULATION_VS_HARDWARE.md) — the lab tier system and what each tier can prove.
* [`docs/VAPT_METHODOLOGY.md`](VAPT_METHODOLOGY.md) — the reasoning loop, severity derivation and evidence standard.
* [`docs/WIRELESS_VAPT_CHECKLIST.md`](WIRELESS_VAPT_CHECKLIST.md) — the 42-item master checklist.

The historical content is preserved in git history (commits before 2026-09-28) if it is needed for reference.
